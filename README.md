# 黄沙边镇 · Yellow Sand Gulch

> 西部荒野体素小镇 24 小时动态昼夜系统 · Three.js 程序化 3D 场景源码

## 项目简介

《黄沙边镇》是一座基于 Three.js 构建的完整沉浸式西部荒野体素风小镇。场景以 0.2 米/voxel 精细度程序化生成，包含约 37 万个多边形面，集成完整的 24 小时动态昼夜光照演进与自动环游导览系统。

## 场景特色

- **纯程序化几何构建**：所有主街木屋、西部沙龙（Saloon）、旅馆、火车站、水塔、钟楼与峡谷地貌均通过代码逻辑程序化生成。
- **24小时昼夜系统**：
  - 太阳与月亮按真实物理弧度升降；
  - 天空色阶、大气雾效、漫反射与直射阴影实时计算；
  - 傍晚与入夜后，街灯、室内窗棂灯火、营火次第点亮。
- **动态蒸汽火车与荒野元素**：
  - 行驶在峡谷轨道上的蒸汽机车（车厢、烟雾粒子、鸣笛水塔）；
  - 旋转的风车、随风滚动的风滚草、仙人掌与帐篷营地。
- **全方位导览**：支持自由键鼠飞行漫游（WASD + QE + 鼠标环视）与一键自动巡航航拍（主街 → 铁路 → 峡谷水塔 → 钟楼 → 山道 → 瞭望台）。

## 构建与测试

项目提供纯净的离线打包管线：

```powershell
# 运行 PowerShell 组装脚本，输出自包含 HTML
.\make.ps1

# 运行自动化几何与冒烟测试
node smoke.js
```
